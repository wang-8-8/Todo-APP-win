# 课表清单（Schedule Todo）

结合 WakeUp 课表与滴答清单风格的电脑版应用：**周视图课表 + 待办清单**，单文件 HTML，浏览器直接打开即用，数据保存在本地。

## 功能

### 课表（WakeUp 风格）
- 周视图网格：周一至周日 × 节次，今日列高亮
- 添加课程：名称、星期、起止节、地点、老师、8 种课程颜色、周数范围（如 `1-16`，留空为每周）
- 点击课程块可编辑 / 删除，点击空白格快速添加
- 课表设置：学期开始日期（自动计算当前周）、每天节数、每节起止时间自定义
- 顶栏可手动切换当前周，显示该周日期范围

### 待办（滴答清单风格）
- 新增任务（可选分类：身体 / 创意 / 心理 / 社交）、勾选完成、删除（可撤销）
- 分类筛选、顶部完成进度条
- 粘贴导入 / 导出任务文本（支持 `#分类` 与 `[x]` 完成标记）
- 一键载入示例清单

### 数据
- 全部数据本地存储（localStorage），离线可用
- 导出 / 导入全部数据（JSON 备份，换电脑一键迁移）

## 使用

直接用浏览器打开 `index.html` 即可，无需安装、无需网络。

schedule-todo/
